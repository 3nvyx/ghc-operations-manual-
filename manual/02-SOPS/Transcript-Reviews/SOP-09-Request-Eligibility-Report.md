# Request Eligibility Report

Use this SOP when requesting OIE data to identify students who appear eligible for honors opportunities.

## Report Purpose

OIE reports support invitation campaigns and preliminary eligibility review. They should not be treated as final transcript evaluations.

## Typical Requested Data

- Most recently completed grading period.
- Current enrollment status.
- Cumulative OCC GPA.
- Completed coursework and units.
- Course-level indicators, including whether coursework below A100 appears in the completed unit count.
- Current student contact information as available.

## Process

1. Define the society, program, or campaign audience.
2. Request the needed data from Institutional Effectiveness.
3. When the Excel report is received, preserve the raw file.
4. Filter the data for the relevant eligibility threshold.
5. Flag coursework below A100 when it may affect eligibility.
6. Use "appears eligible" language in student communications unless a full transcript review has been completed.

## Examples From Source Notes

- PTK filtering may remove students below a 3.50 cumulative GPA and flag students with coursework below A100 for manual review.
- Honors Program filtering may remove students below a 3.25 GPA and students without an A or B in a qualifying English composition class or Philosophy A150.
