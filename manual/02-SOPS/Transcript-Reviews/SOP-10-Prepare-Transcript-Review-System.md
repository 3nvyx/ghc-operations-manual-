# Prepare Transcript Review System

Transcript reviews are organized in Google Drive so eligibility decisions can be reused during application processing.

## Source Location

Use Google Drive file **1. HONORS TRANSCRIPT REVIEW REQUESTS**.

## Process

1. Open the current semester folder.
2. Locate or create the workbook for the student's last-name range, such as A-B or C-D.
3. Add or locate the student's review entry.
4. Attach or reference the relevant transcript source.
5. Record qualifying coursework, units, GPA, eligibility decision, and notes.
6. Make the review easy to locate later during application processing.

## Standard

Reviews should identify the evidence used to decide eligibility. If the review relies on assumptions or incomplete transcript information, mark that clearly.
