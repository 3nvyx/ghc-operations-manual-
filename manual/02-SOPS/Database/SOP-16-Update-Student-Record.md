# Update Student Record

Update an existing Access record when a student submits a new application, renewal, updated General Information form, payment, welcome letter, report, or notation.

## Process

1. Search the database by student ID.
2. Open the existing student record.
3. Use the orange Edit Information button to update general information.
4. Open the relevant society or Honors Program card.
5. Enter the new application, renewal, payment, billing, welcome letter, report, or transcript notation information.
6. Save and close.
7. Confirm that no duplicate record was created.

## Record Standard

Access should show the student's current information and a clear history of each honors affiliation.
