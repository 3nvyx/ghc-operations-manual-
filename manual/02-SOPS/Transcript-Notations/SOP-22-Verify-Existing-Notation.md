# Verify Existing Notation

Use this SOP before adding a new Banner transcript notation or when reconciling Access records against Banner.

## Process

1. Open Banner 9 and go to SHATCMT.
2. Enter the student ID number and use OC for the level.
3. Review existing honors or society notations.
4. Compare Banner entries against the student's Access membership cards.
5. Confirm the society code, effective date, and whether the notation already exists.
6. If the notation exists, do not insert a duplicate.
7. Record the existing notation status in Access if it was missing from the database record.

## When to Escalate

Ask for help from Student Records or Faculty Services if:

- A notation appears under the wrong code.
- A duplicate notation exists.
- Banner does not allow a needed correction.
- Access and Banner conflict and the supporting documentation is unclear.
