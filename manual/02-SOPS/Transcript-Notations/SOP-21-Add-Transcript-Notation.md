# Add Transcript Notation

Use this SOP when a student has earned a Permanent membership or other honors status that should appear on the OCC transcript.

## Before You Begin

Confirm:

- The membership or honors status has been fully verified.
- The Access record shows the correct society, level, qualifying semester, start date, and payment or billing status.
- The transcript notation is not already present in Banner.
- You have the correct notation code for the society or program.

## Banner 9 Process

1. Open Banner 9.
2. Request the PROD page **SHATCMT**.
3. Enter the student ID number.
4. Use **OC** for the level when prompted.
5. Review the student's existing transcript notations.
6. If the notation does not already exist, choose **Insert**.
7. Select the correct society or honors notation code.
8. Use the membership start date as the effective date.
9. Save the entry.
10. Return to Access and record the transcript notation date.

## Common Codes

- 1AB = Alpha Beta Gamma
- 1AG = Alpha Gamma Sigma
- 1AM = Alpha Mu Gamma
- 1EO = Eta Eta Omicron
- 1IO = Iota Xi
- 1MA = Mu Alpha Theta
- 1MD = Mu Delta Rho
- 1NT = National Technical
- 1OP = Omega Psi Sigma
- 1PA = Phi Alpha Mu
- 1PT = Phi Theta Kappa
- 1PR = Pi Rho Sigma
- 1PE = Pi Tau Epsilon

## Caution

If other societies are already listed, insert the new society in the correct alphabetical position when the system allows. Do not create duplicate notations.
