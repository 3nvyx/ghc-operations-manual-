# Process Honor Society Application

Use this SOP for a standard honor society application when the student has submitted all required documents and is either paying personally or requesting payment through an approved program.

## Required Application Materials

- General Information form, submitted through Google form or PDF.
- OCC transcript, included through the General Information form link or submitted separately as PDF.
- Transcripts from other colleges or high school, when needed to establish eligibility.
- Specific honor society application form, usually submitted by email. PTK may be an exception when the student applies directly through PTK and pays personally.
- Membership fee receipt from OCC Tickets, or indication that a billable program will pay the fee.

## Process

1. Open the student's application folder in Outlook.
2. Confirm all required documents are present.
3. Open the Access database from the O drive: Honors > Database > Honors_Database_fe.
4. Search the Access database by student ID.
5. If the student already has a record, update the general information using the General Information form and the orange Edit Information button.
6. If no record exists, create a New Application using the blue button, enter the General Information form details, save, and return to the student record landing page.
7. Look for a transcript review in Google Drive file "1. HONORS TRANSCRIPT REVIEW REQUESTS."
8. Locate the current semester folder and the workbook for the student's last-name range.
9. If a transcript review exists, use it to confirm eligibility, qualifying units, and qualifying GPA.
10. If no transcript review exists, review the transcript against the society application criteria.
11. Open the correct society membership card in Access.
12. Enter the date all application materials were received as the membership start date.
13. Enter the previous semester as the qualifying semester.
14. Record payment date and amount in the correct payment field.
15. Send the welcome letter from the current semester field.
16. If the membership is Permanent, review whether a Banner transcript notation is required.
17. File processed documents in the correct Outlook or Google Drive archive location.

## Important Notes

- Honor society eligibility is based on coursework completed through the previous semester.
- The qualifying semester and processing semester are usually consecutive.
- A student qualifies for only one membership level at a time and should be processed at the highest level for which they qualify.
- Welcome letters are stored on the O drive under Honors > Welcome Letters and should be updated each semester.
