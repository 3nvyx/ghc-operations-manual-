# Send Welcome Letter

Welcome letters confirm that a student's membership or program enrollment has been processed and provide next steps.

## Process

1. Confirm the application is complete and eligibility has been verified.
2. Confirm payment or program billing authorization is resolved.
3. Open the student's Access record and the relevant society or Honors Program card.
4. Use the welcome letter field for the current semester.
5. Confirm the letter template has been updated for the current semester, dates, and society president when applicable.
6. Send the welcome letter.
7. Confirm the database records the welcome letter date automatically or enter the date if required.

## Template Location

Welcome letters are stored on the O drive under Honors > Welcome Letters and are linked to fields in the relevant Access cards.

## Quality Check

Before sending, verify:

- Student name and email address.
- Society or program name.
- Membership level.
- Semester references.
- Payment or billing status.
- Any next steps for meetings, certificates, materials, regalia, or parent organization membership.
