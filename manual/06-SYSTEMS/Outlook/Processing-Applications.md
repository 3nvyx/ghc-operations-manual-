# Processing Applications

Most applications arrive by email and are organized in Outlook folders before processing.

## Folder Pattern

Application folders are commonly labeled with:

- Date received.
- Student name.
- Society abbreviation or societies requested, for honor society applications.

Process the oldest complete application files first unless a deadline requires different prioritization.

## Application Folder Review

1. Open the student's application folder.
2. Review all attachments.
3. Confirm the General Information form, society application, transcripts, and payment or billing indication are present.
4. Identify missing documents before database entry whenever possible.
5. Keep correspondence with the application folder so another staff member can review the processing history.

## Status Routing

- Complete applications move into processing.
- Missing-document applications need follow-up.
- Pending applications should be held for grades, coursework, documentation, payment, or program authorization.
- Processed applications should be archived in the office filing structure.
