# Student Records

Student records in Access are the central reference for GHC processing history.

## Search Before Creating

Always search by student ID before adding a new application. Duplicate records make eligibility, payment, welcome letter, and transcript notation tracking unreliable.

## If a Record Exists

1. Open the student record.
2. Update general information using the General Information form.
3. Use the orange Edit Information button when needed.
4. Open the correct society or Honors Program card.
5. Enter membership, payment, welcome letter, reporting, or notation updates.

## If No Record Exists

1. Use the blue New Application button.
2. Enter the General Information form details.
3. Save and close.
4. Return to the student landing page.
5. Continue processing the society or program card.

## Record Quality

The record should show what was received, what was verified, what level was approved, what was paid or billed, what communication was sent, and what reporting or notation was completed.
