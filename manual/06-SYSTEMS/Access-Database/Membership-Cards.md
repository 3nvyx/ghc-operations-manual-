# Membership Cards

Membership cards are the Access screens that track a student's status in a specific honor society or in the Honors Program.

## Common Fields

- Membership level.
- Membership start date.
- Qualifying semester.
- Qualifying units.
- Qualifying GPA.
- Payment date and amount.
- Program billing status, if applicable.
- Welcome letter date.
- Parent organization report date.
- Transcript notation date, if applicable.

## Entry Standard

- Use the date all application materials were received as the membership start date unless the society or program requires otherwise.
- Use the previous semester as the qualifying semester for standard honor society applications.
- Enter payment and welcome letter information in the current processing semester fields.
- Use transcript review data for qualifying units and GPA whenever a review exists.

## Caution

Make sure the payment and welcome letter fields match the processing semester, not the qualifying semester.
