# Access Database Overview

The Access database tracks honors students and the organizations or programs in which they participate.

## Purpose

Use Access to maintain:

- Student general information.
- Honors Program records.
- Honor society membership cards.
- Membership levels and qualifying semesters.
- Payment and program billing records.
- Welcome letter dates.
- Parent organization reporting status.
- Transcript notation status.

## Student Record Structure

Each student has a landing page with general information and separate buttons for each honors affiliation. Each button opens a card that contains only the student's record for that society or program.

## Standard Workflow

1. Search by student ID before creating any new record.
2. Update an existing record when one exists.
3. Create a New Application only when no student record exists.
4. Enter society or program data on the correct card.
5. Save and close after updates.
6. Keep Access aligned with Google Drive, Outlook, Banner, OCC Tickets, and billing records.
