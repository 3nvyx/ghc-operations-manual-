# Transcript Review System

The Google Drive transcript review system supports eligibility decisions for Honors Program and honor society applications.

## Main File

Use **1. HONORS TRANSCRIPT REVIEW REQUESTS** as the main reference point for review tracking.

## Organization

- Current semester folder.
- Workbooks organized alphabetically by student last name, often two letters per workbook.
- Student-level review entries that record qualifying coursework, units, GPA, eligibility notes, and decision status.

## Use During Application Processing

1. Open the current semester folder.
2. Locate the workbook for the student's last-name range.
3. Search for the student.
4. If a review exists, use it to complete qualifying units and GPA in Access.
5. If no review exists, complete or request the needed review before final eligibility approval.

## Quality Standard

The review should make clear whether the student is eligible, not eligible, or pending because information is incomplete.
