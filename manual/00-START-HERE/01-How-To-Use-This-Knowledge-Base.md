# How To Use This Knowledge Base

Use this knowledge base as a continuous operations guide rather than a set of disconnected notes. Start with the broad operations sections when learning the office context, then use the SOP sections when completing a specific task.

## Recommended Workflow

1. Identify the task category, such as application processing, transcript review, billing, finance, events, or annual closeout.
2. Open the matching SOP and follow the steps in order.
3. Check related system pages when the SOP references Access, Banner 9, Google Drive, Outlook, OCC Tickets, or OIE reports.
4. Use appendices for codes, contacts, billing rules, and acronyms.
5. Record completed work in the correct system, not only in email or notes.

## When Information Is Incomplete

Some sections are still being developed from source material. If a section gives the general process but not a final contact, form name, fee, or deadline, confirm the detail in the current office file, Google Drive, Banner, Access database, Bursar documentation, parent organization portal, or with the responsible campus office.

## Reading Continuously

The manual is intended to be read as one continuous document. The outline highlights the section currently in view, while file and folder names indicate where that section lives for maintenance.
