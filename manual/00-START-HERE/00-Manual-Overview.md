# Manual Overview

The Garrison Honors Center (GHC) Operations Manual documents the recurring work needed to support OCC honors students, honor society members, Honors Program participants, student leaders, and partner programs.

## Purpose

Use this manual as the working reference for:

1. Processing Honors Program and honor society applications.
2. Verifying eligibility, transcript reviews, payments, and program billing.
3. Maintaining Access database records, welcome letters, parent organization reporting, and transcript notations.
4. Coordinating financial processes, events, travel, graduation recognition, publications, and annual closeout tasks.

## How the Manual Is Organized

- **Start Here:** Orientation, key contacts, quick reference, and the overall office map.
- **Operations Manual:** Mission, who GHC serves, core responsibilities, annual work, office workflows, and strategic goals.
- **SOPs:** Step-by-step procedures for membership processing, transcript reviews, database work, billing, finance, and events.
- **Honor Societies and Honors Program:** Organization-specific and program-specific reference material.
- **Systems:** Access, Banner 9, Google Drive, Outlook, OCC Tickets, and OIE data workflows.
- **Calendar and Deadlines:** Recurring semester, monthly, and year-end work.
- **Appendices:** Codes, contacts, billing rules, acronyms, forms, and troubleshooting.

## Working Rule

When a procedure depends on current forms, contacts, rates, or system access, confirm the latest version in the source system before acting. This manual should capture the process, but live systems remain the source of truth for current records and approvals.
